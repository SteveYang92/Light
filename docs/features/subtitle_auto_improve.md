## 字幕自改进框架
聚焦light-subtitle包，建立字幕自改进框架

### 现状
- 未建立覆盖不同维度、层次的成功标准
- 缺乏系统性的评估方法，覆盖不同维度、层次
    - 缺少LLM based步骤的评估方法
    - light-qc/light-regression是面向最终产物的验证，主要是基于规则的，规则覆盖不全，难以完全和人的需求对齐（例如一些字幕拆分明显不合适，但qc规则检测不出来）
    - 无面向人类体验的质量评估机制
    - 缺少多语言对的的字幕评估机制
- 字幕管线包含很多处理步骤，这些步骤本身解耦，却无法独立调优
- 字幕管线细节多，流程多，有很多补丁、Hack，稳定性差，复杂度高

### 目标
- 建立关键步骤的成功标准
- 建立系统性的LLM based步骤的评估方法（框架）
- 关键步骤可独立调优
- 面向用户体验设计、面向交互结果设计
- 质量不衰退的前提下，建立更好的字幕生成策略，简化流程，提升稳定性和效率


## 约束
- 分步骤进行，先奠定基础（成功标准、评估框架等），再做管线流程优化
    - 先建立可泛化的方法论、框架
    - 新场景、新策略按已建立的套路、方法轮来优化，通过优化过程和结果也可检验和提升方法论
- 用户体验为导向，如有必要，引入人类反馈
